# ANTARES Web

Frontend web responsivo do ANTARES ERP.

## Responsabilidades

- Interface operacional em navegador.
- Dashboards.
- Telas de cadastro.
- Fluxos de estoque, almoxarifado, caixa e financeiro.
- Relatorios e exportacoes.

## Diretrizes Iniciais

- Interface densa, clara e operacional.
- Navegacao por modulos.
- Componentes reutilizaveis.
- Suporte a desktop e dispositivos moveis.
- Controle de telas por permissao.

## Proximo Passo

Scaffold do frontend React/TypeScript com layout base, rotas e shell autenticado.
