# ANTARES API

Backend REST do ANTARES ERP.

## Responsabilidades

- Autenticacao e autorizacao.
- Regras de negocio.
- API REST por modulo.
- Transacoes de estoque e financeiro.
- Auditoria.
- Integracoes.

## Modulos Planejados

- identity.
- companies.
- access-control.
- catalog.
- inventory.
- warehouse.
- purchasing.
- sales.
- cash.
- finance.
- reports.
- documents.
- ai.
